# 遗传学多功能计算器 使用说明

一个纯前端、单文件的遗传学计算工具。支持移动端浏览，支持深色/浅色主题切换（右上角按钮）。

## 界面布局

页面分为两个区域：

- **左侧「题目设置」**：通过栏目"拼装"出题目条件（题目描述不能直接输入，需逐项配置）。
- **右侧「计算结果」**：设置亲本、世代数与交配方式，点击「开始计算」后生成遗传图解。
- 手机等窄屏设备上，顶部会出现「题目设置 / 计算结果」两个标签页切换按钮。

## 一、题目设置（左栏各栏目）

### 1. 基本设置
- **性别决定系统**：无 / XY 型（♂ 异型）/ ZW 型（♀ 异型）。
- **巴氏小体**：开启后，XX（ZZ）雌性中一条 X(Z) 固缩失活，杂合雌性表型显示为嵌合体（Lyon 化）。

### 2. 核遗传等位基因（二等位）
- 输入对数（0–10），如输入 2 即 AaBb 类题型。
- 每对基因可自定义字母（A/a、B/b…），并可注释显性/隐性性状（如红/白、全翅/残翅）。
- **显隐关系**：完全显性 / 不完全显性（AA、Aa、aa 三种表型）/ 共显性。
- 选择性别决定系统后，每对基因可单独设为常染色体、伴 X(Z)、伴 Y(W) 或 X/Y(Z/W) 同源区段。
- **母系遗传（母性效应）**：勾选后子代该性状由母本基因型决定。

### 3. 复等位基因
- 输入座位数（每座可容纳任意多个等位基因，无上限）。
- 列表**从上到下即显性等级**（上位 > 下位），用 ↑↓ 按钮调整顺序，如 Iᴬ > Iᴮ > i。
- 可勾选"前两个等位共显"（如 ABO 血型中 Iᴬ 与 Iᴮ 共显、均对 i 显性）。

### 4. 细胞质遗传
- 输入细胞质基因数，每个基因可添加多个变体（符号 + 性状注释）。
- 细胞质基因随母本细胞质传递，子代表型完全由母本决定（母系遗传、正反交结果不同）。

### 5. 连锁关系与染色体图
- 三个基因栏目（核遗传 / 复等位 / 细胞质）各自拥有**独立**的染色体图。
- **放置操作**：先设置染色体对数 → 点击下方基因标签选中 → 点击图中染色体上的横线放置。
  - 放置成功后会弹出 **"✅ 放置成功"模态框**，提示基因名、第几对染色体、第几个基因位点，并提醒该染色体上的基因已构成连锁。
  - 模态框提供「↩ 撤销本次放置」（误放一键撤回）和「继续」两个按钮。
  - 点击图中已放置的字母可移除；允许空位、允许同一基因多处放置（计算取第一处）。
- **未放置在图中的基因默认独立遗传（自由组合）**；放在同一对染色体上即连锁，相引（AB/ab）或相斥（Ab/aB）由亲本基因型自动判定。
- 每对染色体上相邻两个基因可输入**交换值（重组率）r**。
  > 交换值定义：两对基因之间**重组型配子**占该对基因全部配子的百分率。r=50% 时等同自由组合，r 越小连锁越紧密；图距 1 cM ≈ 交换值 1%。相引时亲本型各 (1−r)/2、重组型各 r/2。
- **多拷贝染色体（三体/四体）**：每对可设染色体条数（默认 2）；分配方式可选"独立分配（每条 50% 进入配子）"或"n:1 交替式（只产生两类互补配子）"；进入 0 条的配子可选"视为致死"或"存活"。亲本卡片中还可单独设定某个亲本为正常二倍体（支持三体 × 二倍体杂交）。

### 6. 配子致死 / 合子致死
- 配子致死：按条件（含某等位 / 不含）筛选配子，可选作用于雌、雄或两者，可设雌雄不同的死亡率；死亡后剩余配子概率**重新归一化**。
- 合子致死：按条件（含 / 不含 / 纯合 / 杂合）筛选合子，设死亡率；后代比例按存活个体归一化（经典题：显性纯合致死 → 2:1）。
- 多个条件为"且"，多条规则为"或"。

### 7. 基因互作
内置互作类型（括号内为经典 F₂ 比例）：

| 类型 | 机理 | 比例 |
|---|---|---|
| 互补作用 | A_B_ 才表达 | 9:7 |
| 隐性上位 | aa 掩盖 B/b | 9:3:4 |
| 显性上位 | A_ 掩盖 B/b | 12:3:1 |
| 抑制作用 | A_ 抑制 B 表达 | 13:3 |
| 重叠作用 | 任一显性即表现 | 15:1 |
| 积加作用 | A_B_ / A_bb+aaB_ / aabb | 9:6:1 |
| 累加效应 | 显性基因个数分级 | 1:4:6:4:1（两对）等 |
| 基因通路 | 代谢途径 A→B→C | 依编辑而定（可复现 9:3:4 等） |
| 自定义表型表 | 手动指定 ≤3 对基因组合的表型 | 任意 |

- **基因通路**：按代谢顺序排布催化基因（每步可命名"受阻表型"），全通时表现最终产物；可另设一个抑制基因使某一步失活（如 A_B_Cc 仍为白色）。
- **累加效应（连续表型/数量性状）**：勾选参与的基因座（最多 6 对），可启用**连续数值表型**——设置性状名称、单位、基础表型值和每个显性等位的增量，表型值 = 基础值 + 显性等位数 × 增量。n 对基因共 2n+1 级，计算结果页自动绘制**各级频率分布柱状图**（正态钟形分布），并给出各级比例（两对 1:4:6:4:1，三对 1:6:15:20:15:6:1）与表型范围（如株高 150cm–180cm）。

### 8. 经典题型预设
一键载入：隐性上位 9:3:4、互补 9:7、累加效应 1:4:6:4:1、三对基因连续表型（株高）、ABO 血型、连锁与交换、伴 X 遗传、细胞质遗传（紫茉莉型）、显性纯合致死 2:1。

## 二、计算设置（右栏）

- **遗传至第几代**：F₁–F₁₀，逐代计算。
- **交配方式**：
  - 杂交：P（♀×♂）→ F₁，之后各代自交；
  - 自交：同一亲本连续自交至 Fₙ；
  - 自由交配：两种亲本按数量比（默认 1:1）混合，群体内随机交配至 Fₙ。
- **亲本**：下拉选择每个基因座的等位基因组合（含三体亲本的染色体条数、细胞质基因变体、性染色体基因型）。

## 三、计算结果

- **遗传图解**：左侧竖排 P、F₁、F₂… 标签；每代给出各基因型、性状（表型）与精确分数比例；P 下方列出雌/雄配子及其概率；世代之间用箭头标注交配方式。
- **点击 P / F₁ / F₂ … 标签**：弹出模态框，包含
  - **详细计算过程**（每步分行）：配子概率推导（含连锁交换的亲本型/重组型计算）、致死归一化说明、棋盘格受精说明、基因型合并、表型比；
  - **染色体图解**：该代代表个体的染色体图（基因位置、三体条数、性染色体）；
  - 累加效应题型另附**连续表型频率分布图**。
- 多代自交/自由交配采用**逐代迭代**（等价于马尔可夫链转移矩阵连乘），如 Aa 自交至 F₃ 杂合率为 1/8。
- 末代另附基因型-概率-表型明细表。

## 四、计算原理与约定

- 所有概率使用**精确分数**运算，比例为最简整数比。
- 多基因连锁采用"相邻区间独立交换"（无干涉）近似，为教学标准模型。
- 配子致死后剩余配子重新归一化为 1；合子致死后按存活个体归一化，并报告总死亡率。
- 伴 X(Z) 遗传中，雄性（XY 型）半合子的表型直接由唯一等位决定。
- 细胞质基因只通过母本传递，父本设置中不出现。
- 引擎经过 30 余项自动化单元测试验证（3:1、9:3:3:1、9:3:4、9:7、13:3、12:3:1、15:1、9:6:1、1:4:6:4:1、1:6:15:20:15:6:1、连锁测交 4:1:1:4 与相斥 1:9:9:1、致死 2:1、伴性 1:1:1:1、ABO、细胞质、自交 F₃ 杂合 1/8、自由交配 1:6:9、三体 1:1 等）。

## 五、快速上手示例

**示例一：连续表型（数量性状）**

1. 点击「经典题型预设」→「三对基因连续表型(株高)」；
2. 切到右侧（窄屏点「计算结果」标签），可见亲本为 AaBbCc × AaBbCc、株高基础 150cm、每显性等位 +5cm；
3. 点击「▶ 开始计算」；
4. 结果页给出 F₂ 各基因型/比例、表型比 1:6:15:20:15:6:1，以及 150cm–180cm 七级连续表型的频率分布柱状图；
5. 点击 F₂ 标签查看分行计算过程与染色体图解。

**示例二：连锁与交换**

1. 预设「连锁与交换」→ 打开「连锁关系与染色体图」，可见 A、B 已放置在同一对染色体上，交换值 20%；
2. 右侧亲本为 AaBb × aabb（测交）；
3. 开始计算 → F₁ 基因型比 4:1:1:4（亲本型 AB/ab 为主，重组型 Ab/aB 各占 1/6）；
4. 修改交换值观察比例变化；r=50% 时退化为 1:1:1:1。

## 六、常见问题

- **弹出框关不掉？** 已修复：模态框仅在有内容时出现，点 ✕ 或点遮罩空白处均可关闭；如遇旧缓存请 Ctrl+F5 强制刷新。
- **为什么我的基因没有连锁？** 只有放置到同一对染色体上的基因才连锁，未放置的基因一律自由组合。
- **三体亲本怎么设？** 在连锁图中把该对染色体条数设为 3，再在右侧亲本卡片中调整该亲本的染色体条数（支持三体 × 正常二倍体）。
