# 遗传学多功能计算器 使用说明（v2.6）

> 📐 本网页仅用于**题目验算 / 兴趣探究**等场景，请认真对待平时的作业与考试。

一个纯前端、单文件、离线可用的遗传学计算工具。无需安装、无需联网，用浏览器打开 `index.html` 即可使用。支持移动端浏览，支持深色/浅色主题切换（右上角按钮）。页脚显示版本号（当前 **v2.6**），如遇功能不生效请 Ctrl+F5 强制刷新确认版本。

## 界面布局

- **左侧「题目设置」**：通过栏目"拼装"出正推题目条件。各栏目会记住展开/折叠状态。
- **右侧「计算」**：顶部胶囊切换 **「▶ 正推计算」/「◀ 反推推算」** 两个子栏目；下方设置并计算，生成遗传图解。
- 手机等窄屏设备上，顶部出现「题目设置 / 计算结果」标签页切换。

## 一、题目设置（左栏，供正推使用）

### 1. 基本设置
- **启用性染色体**（复选框，默认不勾选）：不勾选时计算完全不考虑性别（常染色体、无 ♂/♀ 标记）；勾选后可选 XY / ZW 型。
- **巴氏小体**（可选，默认关闭）：开启后 XX 中必有且仅有一条 X 固缩失活（每条失活概率各 50%），杂合雌性表型显示为嵌合体（Lyon 化）。**仅雌性（XX）生效，雄性唯一的 X 不失活**；失活发生在合子形成之后、每代重置——生殖细胞中 X 重新激活，配子完全正常，子代不会因此出现 O/缺失。性染色体系统下"自交"按群体内随机交配处理（雌雄异体无自交）。

### 2. 核遗传等位基因（二等位）
- 对数 0–10；自定义字母与显/隐性性状注释；完全显性 / 不完全显性 / 共显性。
- 性别系统开启后每个基因可设 常染色体 / 伴X(伴Z) / 伴Y(伴W) / X,Y同源区段。
- 母系遗传（母性效应）复选框。

### 3. 复等位基因（等级框模型）
- 同一**等级框**内的等位基因显隐性相同、彼此共显；**框的上下顺序**即显隐性等级（上框对下框显性）；每个框标注显性/隐性类别。例：框1[显性] Iᴬ、Iᴮ → 框2[隐性] i，即 Iᴬ = Iᴮ > i。支持任意多级。

### 4. 细胞质遗传
- 基因数 + 变体（符号/性状），随母本细胞质传递（母系遗传、正反交不同）。

### 5. 连锁关系与染色体图
- 三个栏目（核遗传/复等位/细胞质）各有独立染色体图；**染色体对数默认=基因数**（自动跟随），手动修改后以你的设置为准。
- **逐等位基因放置**：点选等位标签（A 或 a 分开）→ 点某条染色体的横线放置。A、a 放到同一对的两条同源染色体上即定义相引（AB/ab）或相斥（Ab/aB）——相位由图上摆放决定。放置成功弹确认框（可一键撤销）。
- 相邻基因间设置**交换值 r**（重组型配子占全部配子的百分率；r=50% 等同自由组合）。
- **多拷贝染色体**（三体/四体）：每对可设条数；分配方式 独立分配 / n:1 交替式；进入 0 条的配子可选致死或存活（显示为 **O**）。亲本卡片可单独设某亲本为正常二倍体。
- 基因字母显示在竖线左侧，紧贴不重叠。

### 6. 配子致死 / 合子致死
- 规则卡片 + 条件行：配子（含/不含某等位，作用于雌/雄/两者，雌雄可不同死亡率）；合子（含/不含/纯合/杂合）。条件间"且"，规则间"或"，任意死亡率。添加规则后栏目自动定位。

### 7. 基因互作
互补 9:7、隐性上位 9:3:4、显性上位 12:3:1、抑制 13:3、重叠 15:1、积加 9:6:1、累加效应（连续数量表型，1:4:6:4:1 等，附频率分布柱状图）、基因通路（A→B→C 代谢编辑含抑制分支）、促进X固缩（偏向性失活，见下）、自定义表型组合表。

**促进X固缩（偏向性失活）**：需启用性染色体（XY 型）并开启巴氏小体。选择一个**伴 X 基因**作为促进因子，并可设置"**该基因所在X染色体固缩率提升至 P%**"：

- **仅雌性（XX）生效，雄性唯一的 X 不失活**；
- **100%（默认）**：携带显性基因的那条 X 完全优先固缩，杂合♀表型确定为另一条 X 的性状；
- **P%（如 60）**：该 X 失活概率提升至 P + (100−P)/2 %，其余随机——杂合♀按此概率**拆分为两个确定表型的组分**参与子代比例计算；
- **0%**：不促进，回到随机失活（杂合♀为嵌合体）。

例：XᴬXᵃ × XᵃY，固缩率提升至 60% → F₁ 为 色盲♀ 9/20 : 正常♀ 1/20 : 正常♂ 1/4 : 色盲♂ 1/4（即 9:1:5:5）。

### 8. 经典题型预设
隐性上位、互补、累加效应、三对基因连续表型、ABO 血型、连锁与交换、伴X、细胞质、显性纯合致死。

## 二、计算子栏目一：正推

- **遗传至第几代** F₁–F₁₀；**交配方式**：杂交 / 自交 / 自由交配（含数量比）。
- **亲本**：下拉选择各基因座等位组合（含三体条数、细胞质、性染色体）。
- **剔除性状（人工选择）**：规则"从第 Fₙ 代起剔除某表型"——该表型个体移出群体、归一化后继续交配，可多规则。正推与反推均生效。
- 结果：遗传图解（P/F₁/F₂… 标签，基因型+性状+精确比例，♀♂配子概率）、点击世代标签看分行计算过程与染色体图解、累加表型分布图。

## 三、计算子栏目二：反推（由比例推亲本与遗传方式）

反推栏目**独立于左栏**，拥有自己的基因设置。操作步骤：

### 第1步：基因设置 + 表型清单 + 图解模式
- **基因**：只需填**字母**（最多 3 个）。性状注释**选填**——互作题型中单个基因的"显性性状"往往无法单独描述，此时留空。
- **表型清单**（推荐）：题目全部表型名，如 `紫,绿,白`。填写后观测可按"**表型名:比例**"填写（如 `紫:12,绿:3,白:1`），表型与比例严格对应（框名"紫色物质"与清单"紫"等互为包含的名字自动匹配）。
- **图解模式**（勾选后启用）：直接按题目中的**代谢/通路图**搭建——
  - **方框 = 物质**（框名即表型名），可拖动、增删、改名；
  - **箭头 = 物质转化**：点框右侧绿色「连」→点目标框的「连」完成连线（箭头自动从框边缘出发、多线自动错开绕行不缠绕）；箭头标签选**催化基因（酶）**——该基因显性时转化才进行，无该显性基因则停留在上一物质（**每条箭头务必选酶**，未选会明确提示）；
  - **分支优先级**（优1/优2/优3）：同一起点分出多支时数字大的产物优先表现；
  - **抑制线**（虚线）："B 抑制 A"表示 B 基因产物缺失时 A 催化的反应失效；
  - **个体表型 = 从前体按优先级推进到的最终物质**。
  - **图结构决定比例类型**：串联通路（白→绿→紫）只能产生 9:3:4 型比例；并行分支+优先级（白→绿(优1)、白→紫(优2)）产生 12:3:1 / 13:3 型。反推无解时先核对图结构与题目比例是否匹配。

### 第2步：推断范围（复选）
尝试伴性遗传（含同源区段雄性两相位）/ 尝试致死 / 尝试基因互作（自动枚举表型分配）/ 亲本为纯合品种 / 显隐性未知（等位互换）。

### 第3步：亲本 P 表型约束
表型清单填写时按**整体表型**选择（互作下 AAbb 表现隐性也算"隐性"）；未填时按基因注释选择。

### 第4步：交配方式
首次（杂交 / P 自交）+ 之后各代（自交 / 自由交配）。伴性方案中"自交"自动按群体自由交配处理；单亲自交与伴性互斥。

### 第5步：各代观测的表型比
两种写法：**纯数字**（`3:1`）或**带名**（`紫:12,绿:3,白:1`，推荐）。可勾选**分雌雄**分别填雌性内/雄性内比例——雌雄比例不同即可判定伴性/同源区段。可添加多代观测（F₁–F₁₀）。

### 自动重算
反推成功过一次后，**修改任何输入都会自动重新反推**：停止输入约 0.6 秒后自动重算并刷新图解与结论，无需再点按钮。「开始反推」按钮保留，供首次使用。

### 结果展示代数
结果图解的代数 = **max(观测最大代数， 正推栏的「计算至第几代」）**；匹配判定仍只针对观测代。

### 结果解读
列出**全部可行解释**：每条注明每个基因的传递方式、致死/互作/通路结构、表型分配、亲本基因型，点「查看」展示完整遗传图解与分行计算。数学上不可分辨的等价解释并列列出。无解时报告尝试组合数并给出排查建议。

### 真题验证示例
1. **烟台 3:5:6:2 题**：基因 A、B，表型清单"阔叶,窄叶"，勾选伴性+互作+纯合，P 表型均"窄叶"，观测 F₁ 分雌雄 1、1 与 F₂ 分雌雄 3:5、3:1 → **A 常染色体 + B 同源区段 + 互补互作，亲本 AAXᵇXᵇ × aaXᴮYᴮ**。
2. **长春 12:3:1 题**（茄子皮色）：互作枚举法 → 显性上位，亲本 AABB×aabb；图解模式：模式一（串联通路）配 9:3:4 有解、配 12:3:1 判无解；模式二（并行+紫优2）配 12:3:1 得 AABB×aabb——**两种模式被严格区分**。
3. 经典：P♀ 显性 + F₁=1 + F₂=3:1 → AA×aa（伴性并列）；F₂=2:1（勾致死）→ 显性纯合致死 Aa×Aa。

## 四、分数输入写法

所有输入概率/比例的地方均支持三种写法：**整数**（20 = 20%）、**小数**（12.5 = 12.5%）、**分数**（1/7 直接作为比例，即约 14.2857…%）。适用位置：

- 交换值（如 1/7 ≈ 14.29% 重组率）；
- 配子致死 / 合子致死死亡率（如致死率 1/7 → 含该等位配子存活 6/7）；
- 促进X固缩的固缩率（如 1/2 → 显性所在 X 失活概率 3/4）；
- 正推 / 反推的各代表型比（如 1/7:2/7:4/7，或带名 紫:1/7,绿:2/7,白:4/7）。

分数全程按精确分数参与运算，无舍入误差。观测比例按精确值匹配（1/7:2/7:4/7 与 1:2:4 视为同一比例）。

## 五、计算原理与约定

- 全程**精确分数**运算；多基因连锁用相邻区间独立交换（无干涉）近似。
- 配子致死归一化为 1；合子致死按存活归一化并报告总死亡率；剔除规则同样归一化。
- 同源区段异配雄性基因型保持 X前Y后 有序（XᴮYᵇ ≠ XᵇYᴮ）。
- 巴氏小体仅雌性 XX：必有且仅一条 X 失活（各 50%）；雄性 X 不失活；部分固缩率下杂合♀按概率拆分为确定表型组分；失活每代重置，不影响配子。
- 反推比例匹配默认忽略子代性别标记（总体比）；分雌雄观测可区分。
- 引擎经 100+ 项自动化单元测试（经典比例、连锁相位、致死、伴性、ABO、细胞质、自交迭代、三体、通路图双模式、模糊名匹配、部分固缩率、分数输入、真题反推、自动重算等）。

## 六、常见问题

- **可以写分数吗？** 可以。所有概率/比例输入框支持 1/7 这类分数写法（详见「分数输入写法」一节）。
- **弹出框关不掉 / 功能不生效？** 多为浏览器缓存旧脚本：查看页脚版本号（应为 v2.6），Ctrl+F5 强刷。
- **反推找不到方案？** ① 观测用带名写法；② 勾选"尝试致死/互作/显隐性未知"；③ 纯种题勾"纯合品种"；④ 互作题基因显隐性性状留空、改填表型清单；⑤ 分雌雄比例不同的题用"分雌雄"观测；⑥ 图解模式核对图结构与比例类型；⑦ 每条箭头务必选催化基因。
- **为什么列出很多方案？** 同一比例在数学上可能对应多种不可区分的假设，计算器如实并列；增加亲本表型约束或分雌雄观测可缩小范围。
