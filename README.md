# 遗传学多功能计算器 使用说明（v3.0）

> 📐 本网页仅用于**题目验算 / 兴趣探究**等场景，请认真对待平时的作业与考试。

纯前端、单文件、离线可用：用浏览器打开 `index.html` 即可，无需安装、无需联网。支持移动端，右上角可切换深色/浅色主题。页脚显示版本号（当前 **v3.0**）；若功能不生效请 Ctrl+F5 强刷确认版本。

## 一、本次（v3.0）相对 v2.6 的改动

### 0. 反推输入大幅简化（v3.0）
- **基因改成一张紧凑表格**：表头「# / 字母 / 显性性状 / 隐性性状」只出现一次，一行一个基因，删除按钮变成 `✕`（原来每行都重复三个文字标签，看着累）。
- **所有长说明收进默认折叠的「点开看」小块**：面板默认只看到标题、输入框和按钮，不再被大段文字淹没。
- **连锁/交换值收进「高级 · 连锁与交换值」折叠区**（默认每个基因各占一对染色体＝自由组合）；一旦设了连锁会自动展开。
- **表型清单简化为一行**：`表型清单 [紫,红,白]` + 一句提示；而且在第 5 步敲带名比例（如 `紫:9,红:3,白:4`）时，**会自动把表型名补进清单**（你已填过就不覆盖）。
- **亲本 P 表型只有一行**（P♀ / P♂ 两个下拉），不再随"有没有表型清单"来回切换；按单个基因约束的选项收进「高级」折叠区。
- **新增 3 个一键示例**：`单基因 3:1`、`两基因 3:1`、`两基因 9:3:4`，点一下就把基因、性状、表型清单、观测比例都填好，可直接看结果。
- 顺带修掉一个真 bug：输入性状后本应刷新「亲本表型」下拉，但刷新函数名写错（`refreshRevPhenSelects` 未定义）导致 250 ms 后抛异常、下拉不更新。现已实现该函数并加入回归测试。
- 修掉「点尝试从性遗传后，右列的致死 / 纯合品种 / 显隐未知 三个 √ 被清空」：反推面板原先把 `S.rev` 捕获进闭包，而 `runReverse` 恢复状态时用 `S=SAVED` **整体替换**了状态对象，于是之后的勾选写到"死对象"上，一重建面板就丢。现改为 Proxy 实时转发到当前 `S.rev`。
- 连锁说明里的 `<b>` 改为按 HTML 渲染（之前标签会原样显示成文字）。

### 1. 染色体图重新设计（细胞视图）
- 椭圆＝**细胞**，竖线＝**染色体**（不同对用不同颜色），小圆＝**着丝粒**，短横线＝**基因位点**。
- 三体/四体/五体/六体画得明显更长并标注「三体（2n+1）」等；**缺体（0 条）用虚线空位与 O 标注**。
- 基因字母统一放在竖线**左侧**（向右偏移量很小），不再与竖线/横线重叠。
- 每对染色体有**可点击的标签**（第1对·2条），点一下只显示该对，便于密集基因编辑。
- 图例、每对条数选择、增加/减少染色体对按钮都在图下方。
- **放置成功后弹模态框**并提示「是否连锁 / 相引还是相斥」，可一键撤销。

### 2. 知识性错误修正
| 项目 | 修正内容 |
|---|---|
| 交换值上限 | 交换值 = 重组型配子占该对基因全部配子的百分率，**理论上限 50%**。填 80% 等超限值时自动按 50%（自由组合）计算，并在计算过程里给出提示。 |
| 累积效应数值 | 修复「基础值 150 被当成 15000」的量纲错误（数值输入统一按分数/小数解析）。 |
| 三体配子 | Aaa 三体独立分配 → A : Aa : Aaa : a : aa = 1:2:1:2:1（总配子 7 份）；AAA → AAA:AA:A = 1:3:3。 |
| 连锁与自由组合 | 同对染色体上的基因才连锁；放到不同对即为自由组合，图上结构与计算结构严格一致。 |
| 空表型 | 未填写性状注释的基因不再产生空字符串表型，避免比例匹配被污染。 |
| 缺体配子 | 统一用 **O** 表示。 |

### 3. 性能优化（多代不再明显卡顿）
- **配子表记忆化**：同一基因型+性别角色的配子表只算一次（多代迭代时重复调用极多）。
- **群体→下一代记忆化**：自交/自由交配结果按"群体内容"缓存，自交后期群体高度重复时可整代命中。
- **缓存安全副本**：缓存对象不再被调用方改写（此前会导致后续世代比例错乱，是本次修掉的一个隐蔽 bug）。
- **比例化简防爆**：分母 lcm 超阈值时退化为逐项分数显示，避免复杂多代卡死。
- **打字轻量刷新**：输入基因字母/性状时只重绘受影响的栏目，不再整页重建。

### 4. 计算过程详细化（仿生物试题标准答案）
点击 P / F₁ / F₂ … 世代标签，弹窗内按**分行步骤**给出，每步之间用 **∵（因为）/ ∴（所以）** 串成完整推理：

1. 雌配子（卵细胞）的形成：染色体位置与连锁关系、交换值、减数分裂结果、每种配子的概率与百分数、**概率和校验＝1**（表格）；
2. 雄配子（精子）的形成（同上）；
3. 受精作用：**棋盘格（Punnett square）**——行＝♀配子、列＝♂配子、格内＝子代基因型与概率；
4. **合并同类项**：相同基因型的格子概率相加（表格）；
5. Fₙ 基因型与概率汇总；致死基因型（若有）；Fₙ 表型与比例（含合计校验与最终比例式）。

> 小节标题不再带「【一】【二】…」序号，直接以内容作标题（如「F2 基因型与概率汇总」）。

> 表格与棋盘格是**真正的表格控件**，会随每一步的计算插在步骤之间（早期版本会显示成 `[object HTMLTableElement]`，已修复）。

### 5. 反推栏目
- **性状可选列表即时更新**：给基因填了「显性性状 / 隐性性状」后，下方「亲本表型」下拉会在 250 ms 内自动出现这些性状——**这是本次修复的重点**（此前只读"表型清单"，导致很多题推不了）。
- 「表型清单」与基因性状注释都支持半角/全角逗号、顿号、分号分隔。
- 新增「基因在染色体上的位置」：同一对＝连锁（可填交换值），不同对＝自由组合；默认每个基因各占一对染色体。
- 互作类题型（9:3:4 / 12:3:1 / 9:7 / 15:1 / 13:3 / 9:6:1）**无需任何额外设置**：勾选「尝试基因互作」后，
  计算器会自动考虑"题目未写出的互补基因"并给出解释。（早期版本曾提供「可选基因对数（额外基因）」输入框，
  经确认多余且容易误导，**已移除**。）

### 6. 其他
- 「基本设置」中**性染色体需勾选才开启**；不勾选时基因传递方式只剩「常染色体」，子代也完全不分性别。
- **巴氏小体为可选项**（默认关闭），仅雌性 XX 生效、雄性唯一 X 不失活。
- 每对基因默认占一对染色体（即自由组合），新增基因会自动排到空余的染色体对上。
- 复等位基因按等级框编辑（同框共显、框序即显隐性等级），用法与二等位基因一致。

## 三、题目设置（左栏）

1. **基本设置**：是否启用性染色体（XY / ZW）、是否启用巴氏小体（可选）。
2. **核遗传等位基因**：0–10 对；自定义字母、显/隐性性状注释；完全显性 / 不完全显性 / 从性遗传；母系遗传（母性效应）；开启性染色体后每对基因可选 常染色体 / 伴X(伴Z) / 伴Y(伴W) / 同源区段。
3. **复等位基因**：等级框模型；同框内共显，框的上下顺序即显隐性等级。
4. **细胞质遗传**：基因数 + 变体（符号/性状），随卵细胞质传递（母系遗传，正反交不同）。
5. **连锁关系与染色体图**：三个栏目各自独立的染色体图；逐等位标签放置；相邻基因填交换值（支持分数，如 1/7）；多拷贝染色体（三体等）可设每对条数与配子分配方式（独立分配 / 严格 n:1），进入 0 条的配子可设为致死或存活（记作 O）。
6. **配子致死 / 合子致死**：条件行（含有/不含/纯合/杂合某等位；雌/雄/两者/雌雄不同死亡率），条件间"且"、规则间"或"；添加规则后栏目自动保持展开并滚动到该栏目。
7. **基因互作**：互补 9:7、隐性上位 9:3:4、显性上位 12:3:1、抑制 13:3、重叠 15:1、积加 9:6:1、累加效应（连续数量性状，1:4:6:4:1 等 + 频率分布图）、基因通路（含抑制分支）、促进X固缩（偏向性失活）、自定义表型组合表。
8. **经典题型预设**：隐性上位、互补、累加效应、三对基因连续表型、ABO 血型、连锁与交换、伴X、细胞质、显性纯合致死。

## 四、正推计算（右栏 · 子栏目一）

- **计算至第几代** F₁–F₁₀；**交配方式**：杂交 / 自交 / 自由交配（可设两种亲本数量比）。
- **亲本**：下拉选择各基因座等位组合（含三体条数、细胞质、性染色体）。
- **剔除性状（人工选择）**：规则「从第 Fₙ 代起剔除某表型」，该表型个体移出群体、剩余比例归一化后继续交配。
- 结果：遗传图解（P/F₁/F₂… 标签、基因型+性状+精确比例、♀♂配子概率）、点击世代标签看**分行计算过程与染色体图解**。
- **频率分布**：不再只限累加效应——**每一代**（F₁、F₂ … 不只最后一代）下面都会显示该代的表型频率分布条形图（标签＋条形＋概率/百分数）；最后一代另有柱状分布图。
  - 累加效应（多基因连续数量性状）：按等级 0…2n 排列，柱下标注数值（如 150/155/160cm），标题为「连续表型频率分布（多基因累加）」；
  - 其它模式：按表型（概率降序）排列，标题为「表型频率分布」；任一代点开详情也能看到同样的分布图。

## 五、反推（右栏 · 子栏目二，独立于左栏）

1. **基因设置**：字母 + 显/隐性性状注释（互作题可留空，改填"表型清单"）。
2. **基因在染色体上的位置**：同对即连锁（填交换值），不同对即自由组合。
3. **图解模式**（勾选启用）：按题目代谢/通路图搭建——方框＝物质、箭头＝转化（**催化基因/酶选择框已加大**，标注为「酶X：X 显性时此步才进行」）、分支优先级、抑制虚线；个体表型＝从前体按优先级推进到的最终物质。
   **抑制线可选两种语义**：`存在时抑制（有A则抑制B）`（默认，A 的产物存在时 B 催化的反应不能进行）／`缺失时抑制（无A则抑制B）`（旧的语义：A 产物缺失时 B 失效）。
   **抑制线随时可加**：点「+ 添加抑制线（有A则抑制B）」即可；若此时只有 1 个基因，会自动补一个基因（抑制关系需要甲乙两个基因）并提示，随后可在下拉里改基因与语义。
4. **推断范围**：尝试伴性、尝试致死、尝试基因互作、亲本为纯合品种、显隐未知。
5. **亲本 P 表型约束**：整体表型约束（互作结构下自动考虑）。
6. **交配方式**：首次（杂交 / P 自交）+ 之后各代（自交 / 自由交配）。
7. **各代观测的表型比**：纯数字（`3:1`）或带名（`紫:12,绿:3,白:1`）；可勾选分雌雄分别填。
8. 结果列出**全部可行解释**并注明遗传方式、互作/致死结构、表型分配与亲本基因型，点「查看」展示完整图解与分行计算。

## 六、分数输入写法

所有概率/比例输入框都支持三种写法：**整数**（20 = 20%）、**小数**（12.5 = 12.5%）、**分数**（1/7 直接作为比例）。适用于交换值、致死率、X 固缩率、各代表型比。全程按**精确分数**运算，无舍入误差。

---

## 七、计算原理与约定

- 全程精确分数运算；多基因连锁按相邻区间独立交换（无干涉）近似。
- 配子致死归一化为 1；合子致死按存活个体归一化并报告总死亡率；剔除规则同样归一化。
- 同源区段异配性别基因型保持 X前Y后 有序（XᴮYᵇ ≠ XᵇYᴮ）。
- 巴氏小体仅雌性 XX：必有且仅一条 X 失活（各 50%）；雄性 X 不失活；失活每代重置，不影响配子。
- 三体等多拷贝染色体：独立分配时按各条进入配子的组合枚举；n:1 交替式只产生互补的两类配子。
- 多代计算（自交/自由交配）采用逐代迭代，等价于马尔可夫链转移矩阵连乘；同一群体重复出现时命中缓存。

## 九、已知问题（诚实说明）

1. **反推的"未写出互补基因"是自动补的，只在互作题型下生效。** 单纯比例（3:1、1:1、2:1 等）不会引入多余基因；
   互作比例（9:3:4、12:3:1、9:7、15:1）会自动把它考虑进去。若题面比例与所填基因数差得太多
   （例如只填 1 个基因却要求 9:3:4），仍可能给出"未找到方案"，此时请补齐基因对数或改用「图解模式」。
2. **连续数值表型的级别数**：当亲本群体含多种基因型时，级别数可能多于 2n+1（因为不同基因型的
   显性等位数不同），这是正确行为；界面提示语仍按"2n+1 级"表述，可能引起误解。
3. **染色体图在基因很密集时会被压缩**，建议点击染色体对标签单独查看该对（再点一次恢复全部）。
4. 自检脚本 `test.js` 依赖同目录的 `testdom.js`（极简 DOM 桩），二者仅供开发自检，发布时只需 `index.html`。

如遇功能不生效，请先确认页脚版本号为 v3.0 并强制刷新（Ctrl+F5）。
